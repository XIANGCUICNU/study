# 科研绘图

此 skill 用于实验或计算数据图；概念插图使用 scientific-schematics 或 generate-image。不得用生成式图片替代实测曲线。

## 工作流程

1. 确认图要回答的问题、数据来源、横纵轴物理量和单位、分组、独立样本数，以及论文/汇报/屏幕用途。读取实际数据后决定图型，不能凭描述造数据。
2. 使用 Matplotlib 的 Figure/Axes API；无 GUI 的批处理使用 Agg。将读取、计算与画图分开，参数集中配置，保留源代码和版本记录。
3. 光谱叠图标明样品、实验条件和归一化方式；堆叠偏移注明偏移量或规则。红外波数递减轴只有在领域习惯或需求下使用，并标注单位；不要把坐标排序与显示方向混为一谈。
4. 拟合图包含原数据、总拟合、必要的分峰与背景，以及共享横轴的残差面板。分峰叠加关系与模型一致，不将平滑线标成原始测量。
5. 小样本组间比较优先显示每个独立数据点，再叠加汇总与区间；误差棒明确 SD/SEM/CI、n 和统计单位。热图注明单位、色标和是否标准化。
6. 坐标尺度、刻度、裁切和对数变换须支持正确解读。绝对大小柱图通常从零起；聚焦谱峰的非零纵轴可以使用，但范围和裁切清楚。避免无解释的双纵轴。
7. 多组同时使用色盲友好颜色及线型/标记，保证灰度可辨；图例不遮峰，文字、单位、指数和希腊字母正确。中文检查字体可用性，不盲设不存在的字体。
8. 先确定最终物理尺寸，再调整字号、线宽和布局。导出 PNG 预览及 PDF/SVG 矢量版；根据目标期刊检查分辨率，通常 PNG 至少 300 dpi，线图按要求更高。嵌入可用字体，不将栅格图转换为 PDF 后宣称为矢量图。
9. 打开导出文件检查截断、重叠、图例、标签、色标、负值和灰度辨识度。检查图中数值与分析输出一致。

## 交付

保存 results/<任务名>/ 下的图、可复现绘图脚本或 Notebook、绘图配置和图注。图注写明样品/条件、处理方式、误差含义和统计方法。用户需要可编辑图时交付 SVG/PDF 与源代码；如要求期刊模板，以其规范优先。
