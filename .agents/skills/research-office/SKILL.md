# 科研办公文件

根据目标文件选择工具，仅安装实际需要的依赖。先检查现有 Python 包和转换工具，不假定当前环境预装了 Office 或 LibreOffice。

## Excel/CSV

- pandas 处理表格，openpyxl 处理 .xlsx 单元格、公式和格式。确认工作表、表头、单位、日期和样品编号；编号保留为文本，防止前导零丢失。
- 原始数据、处理数据、统计汇总和说明分工作表保存，列出来源文件、计算方法和时间。不能静默覆盖原文件或丢弃行。
- 保留公式时使用 data_only=False；读取缓存值时另用 data_only=True。openpyxl 不计算公式：需可用的表格引擎重算，或另导出 Python 验证的数值表，明确缓存未更新。
- 检查公式引用、分母、缺失值、总计与数据行数。不要更改有意的缺失值含义；不自动运行宏。

## Word

- python-docx 创建/编辑 .docx。先定义标题层级、页边距、正文与表格样式、图注、单位和引用。
- 分析报告包含目的、输入和方法、真实结果、图表、限制及复现方式。不虚构文献、实验条件或显著性。
- 使用已有模板时保留其结构；不要声称 python-docx 支持完整的修订痕迹、公式排版或任意复杂模板。转换渲染后核查分页、图注和表格。

## PowerPoint

- python-pptx 创建 .pptx。组会报告围绕研究问题、方法、结果与下一步，每页一个主要信息，图表嵌入清晰且不变形。
- 优先使用可编辑文字和形状；科研图插入 SVG 需确认工具支持，否则用足够清晰 PNG 并附矢量源。图旁保留单位、样本量、误差解释和必要图注。
- 记录图表来源，区分实验结果和概念示意。渲染后检查页边、字体替换、重叠和图像裁切。

## PDF

- pypdf 用于页面合并/拆分与文本读取；pdfplumber 用于版面或表格抽取；reportlab 用于新建 PDF。扫描件需要独立 OCR 工具，OCR 结果须抽查。
- PDF 转表格后核对行列、负号、小数点、指数和单位，不将抽取文本直接当成可信数据。
- 文件转换需要 LibreOffice 或其它可用工具；若不可用，交付原格式并明确哪些页面渲染尚未核查。

## 完成条件

文件能重新打开；数据、公式、图表与分析输出一致；渲染可用时逐页或检查缩略图。交付可编辑源文件、需要的 PDF 和来源说明。不要声称完成了实际没有执行的公式重算、OCR 或版面检查。
