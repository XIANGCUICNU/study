# 光谱数据分析

目标是提供可复现且具有物理依据的结果。按需要调用 exploratory-data-analysis、statistical-analysis 和 research-plotting。

## 1. 明确测量与输入

- 查看文件、表头、仪器元数据和单位。确认光谱类型、横轴（波长 nm、波数 cm⁻¹、能量 eV、时间等）、纵轴（吸光度、透过率、计数、强度）及暗电流/背景/参比。
- 确认激发波长、积分时间、仪器分辨率、样品条件、是否已进行响应校正，以及重复测量和独立样本的区别。缺失信息只在影响方法选择时询问；不影响的分析继续进行并记录假设。
- CSV/TXT 检查编码、分隔符、小数点、仪器导出说明行；Excel 明确工作表和数据区域。不默认第一列一定是横轴。
- 保留原文件，建立输入文件哈希、列映射、单位、筛选区间和软件版本的记录。输出到 results/<任务名>/，不要覆盖 data/raw/。

## 2. 数据质量

- 检查缺失值、非数值、非有限值、重复横坐标、非单调或不均匀采样、饱和、负值及突刺。报告数量、位置范围和处理方式。
- 光谱按横轴排序，同时重排强度和误差列；重复点先判断是否重复测量，不直接删除或平均。负值可能由背景扣除产生，不能一律裁为零。
- 先画原始光谱。异常点处理基于仪器或实验理由；保留原始和处理结果对照。缺失点不静默插值。

## 3. 单位与物理量

- 波数 ν̃(cm⁻¹) = 10⁷ / λ(nm)；能量 E(eV) ≈ 1239.841984 / λ(nm)，仅用于正波长。转换后重新排序，标签清晰。
- 对密度谱从每单位波长转换为每单位能量/波数时，若需保持面积，使用 Jacobian：I_q = I_λ |dλ/dq|。仅转换横轴与转换谱密度是不同操作，明确采用哪一种。
- 拉曼位移 Δν̃ = 10⁷(1/λ_exc − 1/λ_scattered)，波长单位 nm；注明 Stokes/anti-Stokes 符号约定。
- 吸光度 A = −log10(T)，T 应为 0–1 的比例；百分比透过率先除以 100。T≤0 时不能取对数，单独报告。
- 不把相对强度写成绝对辐射强度；不凭峰位单独证明化学物种、跃迁或机理。

## 4. 预处理

- 根据原始光谱和参比选择背景扣除或基线方法（指定无峰区拟合、多项式或 AsLS 等）。记录算法、参数和基线区间；检查基线是否吞掉宽峰或制造负峰。
- Savitzky–Golay 等平滑只在需要时使用，记录奇数窗口和多项式阶数；窗口必须大于阶数并与采样及仪器分辨率相适应。不均匀采样不能直接按等间隔参数平滑。
- 定量拟合优先使用未平滑数据及独立估计的背景；平滑数据可用于初始峰候选。比较不同合理预处理参数对峰位、峰宽和面积的影响。
- 最大值、面积、参比归一化各自改变可比较的量。先说明分析目的，记录因子，保留绝对/未归一化数据。批量处理使用一致规则并逐文件记录失败。

## 5. 峰识别与拟合

- 用 scipy.signal.find_peaks 的 prominence、distance、width 找候选峰；distance/width 的样点单位要与实际横轴间隔对应。候选峰不等于物理峰。
- 根据展宽机制选择 Gaussian、Lorentzian 或 Voigt，并联合拟合背景。写清模型和参数定义，区分峰高与积分面积、σ 与 FWHM。
- Gaussian FWHM = 2√(2 ln 2)σ；Lorentzian FWHM = 2γ。Voigt 宽度使用数值半高宽或注明采用的近似公式。
- 从数据提出初值和合理边界（如正宽度、峰中心在分析区间）。多峰拟合比较多个初值，检查参数卡边界、不可辨识峰和高度相关的参数。
- 仅有可信观测误差时使用误差加权；没有误差时不把残差估计当成已知测量误差。拟合协方差异常或奇异时明确报告。
- 至少输出数据/拟合叠图和残差图；报告模型、拟合区间、样本点数、自由参数数、收敛状态和不确定度。R² 不能代替残差检查。
- 比较同一数据、误差模型和预处理条件下的模型时，可使用 AIC/BIC；不为了高 R² 随意增加峰数。
- 峰面积注明背景、积分区间与方法。有限区间积分和模型全域面积不可混用；非均匀采样用真实横坐标数值积分。

## 6. 重复测量与交付

- 统计独立实验/样品，技术重复不能作为独立样本增加 n。跨光谱对齐须说明插值和共同覆盖区间，不默认外推。
- 区分 SD、SEM、置信区间和拟合参数标准误；说明 n、统计单位和区间估计方法。Bootstrap 应按独立样本或适当的残差结构重采样。
- 输出处理后 CSV、峰参数 CSV/JSON、PNG 和 PDF/SVG、可运行脚本/Notebook、参数配置以及简短分析说明。记录随机种子和依赖版本。
- 先验证脚本能重现结果，再解释峰位/峰宽变化；未执行、缺少参比、超分辨率解释等限制应与相应结论一同说明。
