# 崔翔科研工作汇报

## 限定本次风格
- 将本 skill 视为科研工作汇报的专用配置，不写入全局写作偏好，不修改或覆盖其他风格 skill。
- 服从本次受众、时长、页数和输出形式。只写讲稿时不擅自生成 PPT。
- 对明确的党团宣讲、行政汇报或其他风格请求，跳过本 skill 的结构、语气和视觉规则。若用户同时明确要求将本科研风格用于这些场景，先指出范围冲突并只澄清这一个问题。
- 区分“我的工作进展”“文献中的结果”“我的设想”。纯文献精读交给文献精读 skill；综合科研工作汇报可含文献模块，但须明确作者归属。
- 首次使用读取 [风格依据](references/style-evidence.md)；需要调用词或示例时读取 [调用与输出范式](references/prompts-and-patterns.md)。

## 整理本周材料
1. 读取本次原始材料，建立内部清单：事项、做了什么、目前结果、状态、证据位置、下一步。
2. 以本次资料为事实来源。旧汇报仅提供风格，不移植历史数值、分子、测试条件、完成状态或截止日期。
3. 核对日期。文件名、封面和正文日期可能不同；以本次用户指定为准，不由文件名推断年份或报告日期。
4. 保留实际进度：已完成、进行中、等待结果、未定稿、待补数据。状态依据不足时写“状态待确认”，不把计划说成成果。
5. 按同一问题归并实验、计算和写作事项；缺失材料直接标明，先完成不受缺失影响的部分。

## 按工作讨论顺序展开
根据材料取舍，不机械补齐全部模块：
- **封面**：工作汇报／课题进展 + 本次日期 + 报告人。简洁，不加宣传口号。
- **工作进展**：开头一页用短编号条目交代本周做了什么、推进到哪。通常 3–6 项，材料少则更少。
- **重点工作**：围绕分子设计、合成表征、光谱与寿命、计算、文章图或写作逐项展开。先放对象与图，再解释观察和当前判断。
- **机制讨论**：有新问题或证据时加入。用“为什么会这样”“是否与……有关”保留讨论空间，不预设机制已被证明。
- **文献与方法借鉴**：需要时单列。交代研究问题、关键实验、结果与局限；仅在与当前具体问题有关且材料支持时给出启发。
- **工作计划**：给出近期具体动作、待解决问题和测试依赖。时间、负责人、预约未知时不编造；已给出的时间按原意保留。

## 写出用户惯用的简洁解释
- 用直接、自然的中文，保留必要分子编号与 S₁、T₁、NTO、SOC、ISC、TTET 等专业缩写。
- 用短主题标题，如“正在计算的分子”“吸收光谱”“工作计划”；有明确结论时才用结论式标题。
- 每页围绕一个问题。默认 1–3 条短解释，不搬入完整论文段落。
- 按“对象／条件 → 图中观察 → 物理含义 → 待确认部分”解释。材料不足时省略对应项，不填造事实。
- 优先写具体动作：“完成了……”“目前还在优化”“准备测试……”“需要补充……”。避免“取得显著突破”“全面赋能”等空话。
- 保留“可能、推测、尚未确认”；修正旧稿的错字、残句和过强科学断言。
- 未获得录音或完整演讲稿时，不宣称掌握真实口头禅；讲稿是依据页面文字推导的简洁口语版本。

## 匹配页面习惯
仅在规划或制作幻灯片时应用：
- 用 16:9、白底、黑色正文，少量红字突出关键变化、问题或待补状态。数据颜色依图例保留。
- 让结构、谱图、实验照片、能级图或 NTO 图承担主要信息。优先一张主图配短解释，或左右并列成组对比；不为装饰增加卡片、渐变、插画和背景段落。
- 默认正文约 20–28 pt，标题约 28–36 pt；按投影与版面调整，不为塞字继续缩小字号。出处可小一档但须可读。
- 中文选可用宋体或清晰中文字体，英文与数字可用 Times New Roman，数学用合适数学字体。缺字体时替换并检查渲染，不复制字体补丁名称。
- 对比分子或态时保持相同视角、尺寸、色标、顺序和参数标签。计算页保留态编号、能量及必要的 f、NTO 权重；不把 NTO 的 hole/particle 随意标成 HOMO/LUMO。
- 文章图进展页按 Figure 编号、用途、已有内容、待补证据、定稿状态组织；当前稿件编号优先，不固化历史排序。
- 制作 PPT 时遵循当前环境演示文稿制作与渲染流程，检查中文、上下标、遮挡、图轴和图例。文字提取正常不等于页面渲染正常。

## 保持科研证据边界
- 底稿中区分实验事实、计算结果、文献解释与待验证设想；页面和讲稿用自然表述体现，不必每句加标签。
- 给关键数值保留单位、条件和来源位置；无法辨认写“待核对”。
- 不由氧敏直接断言 TADF，不把单线态氧产率直接等同于 ISC 产率。
- 不以小 ΔE_ST 或单个 SOC 值直接断言 ISC 必然增强；不由单张 NTO 图宣布实验已证实 TBE。
- 不用归一化峰高比较吸收能力；不把跃迁波长自动等同于弛豫态能量。
- 涉及 Φ_UC 时注明 50% 或 100% 上限口径，仅在原始定义明确时换算。
- 按图与拟合真实信息解释 EADS、TA 和动力学；不将 EADS 自动视为纯物种谱。
- 让下一步动作对应证据缺口，不默认新增实验已获准、预约或完成。

## 按请求交付
- **提纲**：逐页给标题、主图／材料、页面短句、结论边界、状态。
- **页面文案**：给可直接放入 PPT 的短句，图注和状态与正文分开。
- **讲稿**：按实际页码写短段落，自然过渡，不逐字重复标题，不为每页重讲背景。
- **PPT**：先落实逐页信息与图，再制作可编辑文件并渲染检查，按当前环境要求保存。
- **修改现有稿**：沿用原顺序和术语，理清逻辑，不自动扩写成答辩或综述。

## 交付前自检
- 确认本次为科研工作汇报，其他风格保持独立。
- 确认开头交代进展，重点页有图或明确材料依据。
- 区分本人工作、文献结果与未来设想，保留未完成状态。
- 清除从旧样本误带的事实；不把不确定结果改成确定结论。
- 检查字号、中文字体、图轴、单位、图注与 Figure 编号。
