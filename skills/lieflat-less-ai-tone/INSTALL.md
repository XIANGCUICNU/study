# Lieflat Less AI Tone

用于中文成稿的去 AI 味处理。入口为本目录的 SKILL.md；仅按规则修改命中的文字，保留原意、事实和文章结构。

## 使用

让支持读取仓库文件的 AI 助手执行：

> 请先读取 skills/lieflat-less-ai-tone/SKILL.md，再按其中规则处理以下文字：……

本目录存放技能文件；仅提交到 GitHub 不会自动启用当前 ChatGPT 对话中的技能。使用时需让助手读取该文件，或按所用工具的技能目录要求安装。

附带的 scripts/ 是语料统计研究工具，不是自动改写程序；运行需 Python 3，使用方法见各脚本开头说明。
