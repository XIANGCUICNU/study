# 化学结构识别与证据核查

## 适用范围

用于用户提供的结构图片、论文、SI、SMILES、Molfile 或 SDF：识别具体分子及结构差异，解释结构设计，并按需生成可复核的结构表示。优先聚焦用户实际问题；可配合 photophysics-paper-deep-reading 使用，但不替代正文与 SI 的独立阅读。

本 skill 是工作流程说明，不自带识别模型、数据库、RDKit 或联网能力。不得声称运行了未实际运行的工具，也不得把模型输出当作已核实的事实。

## 基本原则

1. **来源优先**：记录图片、论文页码、Fig./Scheme/SI 和化合物编号。实际查看结构原图；低分辨率时放大或裁剪，必要时查看上下文、合成路线、图注和 SI。不得用文中名称或想象填补看不清的键。
2. **分开三个层次**：图片中可见的结构；识别软件或模型给出的候选；经其他来源或人工对照验证的结果。工具之间一致也不能单独证明正确。
3. **不确定就明确标注**：原子、键级、连接位点、缩写、电荷、立体化学或重复单元不清楚时，指出具体位置及可能候选；不要凭空补全，不要将候选 SMILES 当作确定结构。
4. **尊重图中信息**：未画出的立体化学为未指定，不能据此判断外消旋或指定 R/S、E/Z；区分盐、反离子、溶剂化物、同位素、形式电荷、自由基及互变异构体。核对楔形键与连接方向。
5. **验证的边界**：RDKit 解析和价态检查仅表明表示可被解析，不能证明与图片一致、结构稳定、合成成功或性质正确。分子式一致、数据库匹配、重新绘图形似均不能单独证明连接关系正确。
6. **区分证据与推测**：标明 [原图可见]、[论文/SI 报告]、[工具结果]、[合理推测]、[无法确认]。性质和机理分析注明来源及条件，不把结构经验推测写成实测。
7. **材料处理**：论文和未发表结构默认使用用户提供的材料及可用的本地工具；外部服务或数据库查询前遵循用户指示和所用环境要求，说明将发送的数据，不假定已联网或已查询。

## 工作流程

### 1. 整理输入和结构对象

- 确认任务是看图解释、对比结构、转换格式，还是分析结构与性质；记录每个样品编号和来源。
- 一张图有多个分子时逐个分离；将编号与结构匹配，避免把反应条件、箭头或邻近结构误认为化学键。
- 优先使用高分辨率原图或 PDF 矢量图；保留完整结构及相关缩写、图注。识别质量不足时说明受影响的位置，必要时请求更清晰图像或原始结构文件。

### 2. 先做逐项结构读取

对每个结构按需记录：主体骨架与环系；杂原子及键级；取代基的身份和位置；连接原子与连接方式；电荷、反离子和立体信息。对相似分子明确列出变动位置，避免只说“增加供电子基团”。

常见缩写按图注和上下文解释，存在歧义则列候选。Markush 的 R、Ar、X、重复单元及附着点原样保留；不要把变量结构冒充确定分子，也不要仅用普通 SMILES 中的 * 丢失变量定义。

### 3. 可选的识别与交叉核对

- 若已具备 MolScribe、DECIMER、MolParser 或其他 OCSR，按其实际输入要求处理结构图，记录工具、版本、输出及失败信息。多工具输出不同则逐项比对，不投票断定真值。
- 若用户提供 SMILES/Molfile/SDF，可直接解析并与原图、名称、合成路线或 SI 对照。若仅有图片，不要求一定生成 SMILES；无法可靠建立结构时，报告部分结构和缺失信息。
- 若 RDKit 可用，对确定的候选执行解析与 sanitization；记录失败、分子式、形式电荷、需要时的分子量和立体信息。用生成的二维结构与原图逐项比较连接、取代位置、键级和立体化学；布局不同不等于结构不同。
- 不同 SMILES 字符串可能表示同一结构。比较时在明确盐、互变异构体和立体化学处理规则后比较分子图或规范化表示；不要把规范化结果误认为原图必然指定的形式。
- 结构含金属配位、自由基、聚合物或 Markush 等情形时，普通 SMILES 和默认价态检查可能不适用；保留原表示和限制，必要时采用适合的扩展格式，不强行转换。

### 4. 结构与性质解释

根据任务解释共轭路径、供体/受体、取代效应、空间位阻和构象等；对激发态、电荷转移、ISC、ROS 等只能结合论文实验或计算证据判断。结构图不能单独证明轨道分布、扭转角、能级、寿命或量子产率。使用图表和 SI 时给出具体位置、条件与数据；区分作者解释和自己的假设。

## 输出格式

按用户需要调整篇幅，默认包含：

1. **输入与来源**：化合物编号、图片或 Fig./Scheme、页码及清晰度。
2. **结构读取**：骨架、官能团、关键连接和取代位置；多样品用对照表。
3. **候选结构表示**：仅在能够可靠构建时提供 SMILES 或其他格式，标明来源、是否已运行解析与绘图核对；未验证的候选明确标注。
4. **设计与性质**：分别给出原文依据和结构推测；未提供数据时不编造。
5. **不确定点与下一步**：列出具体看不清的位置、相互矛盾的证据及可用的核查材料。
6. **实际使用的工具**：名称、版本（可获得时）与执行结果；无工具时说明为人工/模型视觉解读。
