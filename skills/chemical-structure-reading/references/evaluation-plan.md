# 结构识别测试方案

此文档是待执行的测试计划，不是已完成的测试或性能报告。目标是衡量 skill 在实际论文中的端到端表现：结构图读取、样品对应、候选表达、原图复核和不确定性报告。不要用自动生成图的成绩代替真实论文结果。

## 1. 测试材料和标准答案

后续使用可公开获取的论文，或经用户提供并允许用于测试的论文/SI。测试仓库默认只保存来源索引、经允许的引用信息和结果；不要默认提交版权图片或未发表分子。推荐独立留存原始 PDF 和裁图，并记录复现方式、页码、图号、化合物编号及使用权限。

优先构建 15–30 个结构的试验集，涵盖：
- 普通单分子、共轭稠环和杂环；
- 共用骨架但取代位置不同的系列、多结构一页、编号与结构相邻；
- 有 Ph、Me、Boc 等缩写和定义的 R 基/Markush；
- 盐和电荷、指定或未指定立体信息、低分辨率或结构被遮挡；
- 主文与 SI 中不同位置出现同一分子、参比或中间体。

人工标准由熟悉化学结构的人独立依据原图、图注及 SI 确认；按情况保存标准 SMILES/Molfile 和原图标注。Markush 的标准应包含原图、变量定义、附着点及扩展表示，而非仅保存含 * 的 SMILES。不能确认的样本记为待裁决，不计入确定性准确率。

## 2. 独立测试条件

每个工具使用相同原始图或明确记录裁剪差异；记录工具/版本、模型权重、运行设备、预处理、预测次数与参数，以及是否使用正文/SI。区分：
1. 单结构裁图识别，测试识别本身；
2. 多结构页的检测与编号匹配，测试端到端；
3. 结合正文/SI 的最终核对，测试完整 skill。
人工标准与测试输入应区分；先冻结标准再评测，避免凭预测修改答案。

## 4. 检查项目

- **检测和匹配**：漏检、误检、截断、样品标签错配；记录人工总数及检测数。多结构图的分母和单结构裁图的分母不可混淆。
- **结构**：原子身份、环连接、键级、取代位置、形式电荷、反离子和指定的立体信息。普通分子可用明确规则的图同构比较，并另外报告立体是否匹配；记录盐和互变异构体处理规则。完全一致率的分母是有可确认标准的样本数。
- **Markush**：分别评价骨架、变量标签、定义和附着点；保留完整表示，不把普通 SMILES 合法当作完整识别。未能评价的子项写未评价。
- **不确定性**：应标注而未标注的错误，和明确拒绝猜测的情况分别记录；不以模型分数替代人工核查。
- **论文对应**：样品编号、主文/SI 映射、表征出处与实际样品对应是否正确；主文/SI 矛盾能否被指出。

结果按类别分别报告通过数/可评价数、漏检数、无法评价数和例子，不据少量样本声称总体准确率。最终人工核对结果与工具原始输出分开计分。

## 5. 回归场景（尚待运行）

| 场景 | 期望行为 |
| --- | --- |
| 相同分子式的位置异构体 | 指明连接位置差异，不因分子式一致判为相同 |
| 模糊楔形键 | 报告构型存疑，不凭候选补 R/S |
| R1 的定义缺失 | 保留变量及连接点，不输出确定分子性质 |
| 多结构页有漏检 | 标记未检测样品，不将相邻编号错配 |
| 主文与 SI 冲突 | 按来源分别列出，拒绝未经证据裁决 |
| 缺少 RDKit/识别模型 | 明确未运行；保留可见信息、错误及限制 |
| 未提供 SI | 标注未提供，不声称完成 SI 核查 |

## 6. 结果与改进

输出样本级错误清单、类别统计、具体失败图及对应来源（遵守材料使用约束）、工具和版本。分析是检测、识别、后处理、标签对应还是证据推理出错；每次调整后对冻结的样本重跑，并另留新样本，避免只针对已见图片优化。
