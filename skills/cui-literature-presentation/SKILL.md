# 崔翔科研文献汇报

## 明确边界
- 仅应用本次文献汇报，不写入全局风格，不覆盖 cui-research-progress-report、photophysics-paper-deep-reading 或其他风格 skill。
- 首次使用读取 [风格依据](references/style-evidence.md)；需要调用词或结构示例时读取 [调用范式](references/prompts-and-patterns.md)。
- 已有 PPT 写讲稿时按实际页序；从论文新建提纲时按核心问题筛选证据，保持原文论证顺序及依赖关系。用户指定严格按原文顺序时必须遵守。允许删减次要数据，不把结果放到其必要证据之前。
- 明确区分两层：文献精读负责全面读取与证据核查；本 skill 负责选重点、组织页面和讲述。若精读 skill 可用可配合使用；不可用时直接核查当前原文，不假称已调用或以技能缺失为由跳过阅读。
- 本周工作进展用工作汇报 skill，党团宣讲、行政总结等跳过本 skill。综合工作汇报中可仅对文献模块应用本 skill，不把全文改成文献报告。

## 先读材料，再形成汇报线索
1. 阅读用户指定论文、SI、PPT或已有笔记，记录实际可访问范围。图像页须亲自查看；图片文字提取为空不等于该页没有信息。
2. 识别每篇论文的标题、期刊、年份、DOI及对应图片来源。已有PPT没有完整书目信息时标“待核对”，不猜标题、作者和DOI。
3. 建立内部证据表：研究问题、结构变量、测试方法、直接观测量、关键对照、数据与条件、作者解释、局限、Fig./Table/Scheme/页码。
4. 只依据汇报PPT而无法查到论文时，注明“按现有PPT整理，未与原文/SI复核”，不要提升原稿结论的可信度。缺图可给文字方案和明确占位，不虚构曲线。
5. 旧汇报仅作风格参考，不借用旧论文数值、机制和结论解释新文章。引用外部资料仅在用户要求核实、比较或补背景等必要场景使用，附来源。

## 用一个科学疑问串联证据
根据材料选取模块；短汇报可合并，不固定页数：
1. **文献信息与切入点**：简短标题、论文身份及一句话说明为什么值得看。避免长篇学科背景。
2. **核心疑问**：优先用具体对比提出问题，如“结构只差一个连接位置，为什么动力学不同？”只有原文确有相应对比时才如此写，不虚构反常现象。
3. **对象与变量**：并列分子、材料或器件结构，说明改了哪里、哪些条件相同；解释必要的实验流程和部件角色。
4. **现象与对照**：先说图中看到什么，再讲结果支持什么。用少量最关键数据说明差别，不逐个念完全部数值。
5. **方法与机制证据**：按“为什么做这项测试 → 实际测什么 → 怎样从信号得到判断 → 对照排除了什么 → 还不能证明什么”讲清楚。
6. **机制收束**：用简洁能级图、竞争通道或结构—性质关系整合证据，区分作者解释与直接观测。
7. **结论与局限**：用 2–3 点回答开头问题，指出结论适用条件及仍缺证据。不强加工作计划。
8. **可选启发**：默认在末页单列“对我们工作的启发与可操作性”；用户要求独立阅读或不联系课题时除外；区分可迁移的方法、待验证设想与实际已有证据。文献本身的解读仍保持独立。

## 保留用户的讲解方式
- 用直接中文和必要专业术语，以“为什么”“是否”“这里主要看……”推进。问题标题适量，不让每页都变成设问。
- 常用解释路径为“现象 → 简单直觉为什么解释不了 → 关键对照／计算 → 更具体的机制解释”；仅在证据支持时采用，不能编造旧解释已被排除。
- 讲结构变化如何影响态、能量、空间分布或竞争过程；区别热力学可行与动力学快慢，不只说性能提高。
- 围绕一张图或一组对照写短解释，给出读图入口：比较哪条曲线、哪个子图、哪段时间或哪个结构位点。
- 将术语翻译成物理含义，如“这个测量记录的是电流，态归属仍依赖能量扫描、对照或模型”；不要只堆缩写。
- 句子简洁，避免宣传式创新评价和空泛“意义重大”；保留“作者认为”“与……一致”“尚不能区分”等限定。
- 未有完整讲稿或录音时，只称依据页面推导的口语稿，不声称已学到用户真实口头禅。

## 让图承担主要信息
- 默认 16:9、白底、黑色短解释，少量红字突出结构差异、核心数值或机制问题；科学图保留原始图例与颜色含义。
- 优先结构并列、原文子图与短注、光谱／动力学成组对比、机制图收束。正文以约 20–28 pt 为起点，标题约 28–36 pt，按可读性调整；这些是实施建议而非所有旧稿的硬格式。
- 页面只放支撑当前问题的子图，保留轴、单位、必要图例、样品条件和原图编号；不裁掉决定解释的对照，不用截图装饰铺满页面。
- 计算空间分布图用同一视角、等值面与色标；无法确认这些条件时说明，不把视觉色块大小直接量化。
- 关键数值就近标 Fig./Table/Scheme；期刊、年份、DOI在文献信息页及必要图页提供。原文编号和本次幻灯片页码分开。
- 制作实际PPT时遵循当前演示文稿工具流程，渲染核查中文、上下标、图轴、遮挡和图片清晰度。只要讲稿时不擅自生成PPT。

## 字体与证据／结论强调（用户明确要求，2026-10-27）
- 将新增标题、正文、注释与结论制作成可编辑文本，保留字体、字号和文字效果的可修改性；不要将整页或文字栅格化。原文图可保留图片，新增解释文字须独立可编辑。
- 对数据、观测、对照和计算结果等证据短句使用**加粗＋文字阴影＋斜体**；对据此得出的结论使用**加粗＋文字阴影**，默认不加斜体。分别设置文字效果，不用文本框阴影或复制文字模拟。
- 按语义选择强调范围，不按位置、字号或颜色自动判断；同一文本框混有证据、解释与结论时拆分文本框或设置独立文本片段。作者解释和待验证假设保留限定，不能通过证据样式将其当作实证。
- 阴影保持轻微、清晰，不遮挡小数点、上下标和图轴。标题、出处及普通说明不自动套用证据／结论效果。
- 中文采用清晰中文字体，英文数字沿用本 skill 的字体规则；本次指定字体优先。制作前确认字体可用并渲染核查，不把缺字或中文空白的预览视为通过；缺字体时先解决字体或替代并复核。
- 交付前检查文本可编辑、证据的粗体／斜体／阴影与结论的粗体／阴影实际保存在文件中，并核查中文、换行和文字效果的视觉表现。

## 末页联系课题与可操作性
- 科研工作汇报和文献汇报默认在最后一页联系用户当前工作，并说明可操作性；若用户指定不联系课题则遵从。先核对本次可用的研究背景与数据，背景不足时标明并提出可核实的问题，不编造分子、条件或结果。
- 用简洁页面文字分别说明：文献或当前结果可借鉴的具体思路、与用户体系的联系、1–3项可执行的下一步（测试对象、变量、观测量及预期能回答的问题）。区分已有实验事实、建议实验与待验证假设，不把计划描述为已完成或将不同体系的机理直接移植。
- 按现有仪器、样品和资源判断可行性；未知时标“条件待确认”，不假定预约、数据或设备可用。保留必要对照与测量条件，避免笼统口号。

## 不复制旧稿中的科学跳跃
- 区分实验事实、计算结果、作者机理解释和本次推断；证据等级可存备注，用自然句子在讲稿中表达。
- 单线态氧产率不直接等于ISC产率；氧敏、延迟发光或单一温度趋势均不能独自确定TADF／磷光机制。
- NTO、hole/particle、自旋密度和轨道图不是同一物理量；理论空间分布不是实验直接看见激发态分布。电流、光谱等信号推断态或空间信息须交代方法与模型边界。
- EADS取决于全局拟合动力学模型，不自动等于纯物种谱；寿命不自动等于某一步速率常数的倒数。
- SOC矩阵元、能隙与ISC速率不能简单等同；明确参与的态与竞争通道。
- 量子产率标明定义与归一化，Φ_UC注明50%或100%上限；不同条件不直接做倍数比较。
- 不把单个相关趋势说成唯一原因，不把作者解释升级为排他性证明。发现原PPT单位或逻辑错误先标注、再给出可安全复述的句子。

## 按请求交付并自检
- **提纲／文案**：逐页给“标题｜主图及来源｜页面短句｜本页要讲清的问题”，必要时加证据边界。来源未确认要显式保留占位。
- **讲稿**：按实际页码给简短口语段落，说明这页为何出现、读图入口和可得结论；不逐字念表，不自行填数据或扩展成综述。
- **限时汇报**：围绕核心疑问保留必要证据，将次要图移备份；用户未要求时不固定分钟数或页数。
- 核对：是否回答了开头问题？方法讲清了观测量吗？关键结论均有图与条件吗？本人工作与文献归属是否分开？是否强加课题联系或本周计划？是否误用宣讲、工作汇报或全局风格？
