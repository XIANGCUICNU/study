# 专属调用与输出范式

## 一篇论文转组会汇报
> 使用 $cui-literature-presentation，按我的文献汇报风格整理这篇论文和SI。用核心问题串联结构、实验对照与机制证据，解释每张关键图为什么做、怎么看、能说明什么；输出逐页提纲和简洁讲稿，标注Fig./Table，不强行联系我的课题。

## 已有PPT写讲稿
> 使用 $cui-literature-presentation，按这份PPT的实际页序写简洁文献汇报稿，突出读图入口和实验手段如何支持结论，不补造数值；无法核对原文的地方单独标明。

## 主要讲实验手段
> 使用 $cui-literature-presentation，重点讲这篇文章用了什么手段、测量的直接信号是什么、怎样推断单重态和三重态性质、空间分布是实测还是计算。按证据顺序讲，压缩其他部分。

## 多篇主题汇报
> 使用 $cui-literature-presentation，把这些文献围绕同一个科学问题组织成主题组会汇报。逐篇明确来源、条件和作用，最后比较证据与局限，不把不同体系数据当作同条件比较。

## 可选课题启发
> 使用 $cui-literature-presentation，先独立讲清论文，最后单列对我当前课题的方法启发和待验证设想。不要把文献结论说成我们已经完成的结果。

## 三种任务分开
| 任务 | 调用 |
| --- | --- |
| 全面精读、逐项数据及SI核查 | photophysics-paper-deep-reading |
| 将文献讲清楚、逐页提纲、简洁讲稿 | cui-literature-presentation |
| 本周实验计算进展与计划 | cui-research-progress-report |

党团宣讲、行政汇报、答辩等按其专属要求处理，不自动继承以上个人科研汇报风格。

## 虚构的结构示例（不是用户或真实论文结果）
材料：A、B仅连接位点不同；图1给结构，图2为吸收，图3为时间分辨结果。B出现更明显的延迟信号。未提供SI、温度依赖或物种归属。
- 开头问题：连接位点变化后，发光动力学发生了什么变化？
- 结构页：并列图1，标明唯一已知变量，不推断未报告的构型角。
- 现象页：用图2、图3比较谱形和时间行为，不给未提供的峰位、寿命或产率。
- 证据边界页：延迟信号说明存在慢过程，现有材料不足以确定TADF、磷光或其他机制。明确需要原文归属与证据，而非默认作者做过某项测试。
- 结论：目前能确认动力学差异，机制归属待核对。不追加本周工作清单。

讲稿句式：这一页先看连接位置。接下来比较时间分辨结果，B的延迟信号更明显。但仅凭延迟信号还不能确定发光机制，后面需要核对作者是否给出相应对照。
